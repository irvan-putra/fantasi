Write ONE self-contained `index.html`: a 3D map of the Green Pramuka City area in Jakarta, inspired by the viral 1:1 Singapore build, for GitHub Pages.

Data (already on disk, fetched as JSON):
- `data/buildings.json` — `{"bbox":[w,s,e,n], "features":[[height, [[lon,lat],...]], ...]}` (heights are ESTIMATED, meters).
- `data/roads.json` — `{"features":[{"kind":"highway"|"railway"|"waterway", "road_class":..., "name":..., "line":[[lon,lat],...]}, ...]}`.

Requirements:
- MapLibre GL JS from its CDN (jsdelivr, pinned version). No other libraries. No build step.
- Dark custom style with NO external tile or glyph requests (draw only our GeoJSON sources; use a solid background color). Everything works offline once the two JSON files load.
- Buildings: fill-extrusion, height from the data, soft color gradient by height (low = deep blue-grey, tall = warm amber). Roads: thin muted lines by class (toll/primary brighter, residential faint); railway dashed; waterway as dark blue lines.
- Start camera: slow orbit centered on Green Pramuka City (-6.1893, 106.8738), pitch ~60, zoom ~15.2. A "Tour" button flies to 3 named viewpoints: Green Pramuka City towers, Cempaka Putih, Rawasari / the toll-road curve. Free pan/zoom after any user gesture.
- A start card overlay (mobile-first, dismiss button): title "kota — Jakarta at 1:1", one-line explainer, data credit line (Microsoft building footprints, OpenStreetMap contributors), an honest "building heights are estimates" note, and "Generated by GLM-5.3-Flash on Fenrir (fenrir.lio.id), steered by Instinct" in small print. Phone width must not overflow.
- A tiny live counter in a corner: number of buildings and road segments rendered.
- Pure vanilla JS inside the single HTML file (inline <style> and <script type="module">). Handle load errors with a visible message.
